# 0.4 – New Note Diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note over browser,server: User navigates to: https://studies.cs.helsinki.fi/exampleapp

    %% Initial page load (same as 0.1 / review)
    browser->>server: GET /notes
    activate server
    server-->>browser: HTML document
    deactivate server

    browser->>server: GET /main.css
    activate server
    server-->>browser: CSS file
    deactivate server

    browser->>server: GET /main.js
    activate server
    server-->>browser: JavaScript file
    deactivate server

    Note right of browser: Browser executes JS that fetches notes JSON

    browser->>server: GET /data.json
    activate server
    server-->>browser: JSON (existing notes)
    deactivate server

    Note right of browser: Browser renders the notes

    %% New note creation
    Note right of browser: User types note text and clicks "Save" (form submit)

    browser->>server: POST /new_note (form data: note=...)
    activate server
    Note right of server: Server creates note and adds it to its notes list
    server-->>browser: 302 Redirect (Location: /notes)
    deactivate server

    %% Browser follows redirect
    browser->>server: GET /notes
    activate server
    server-->>browser: HTML document
    deactivate server

    Note right of browser: main.css / main.js may be loaded from cache (or re-requested)

    browser->>server: GET /data.json
    activate server
    server-->>browser: JSON (now includes the new note)
    deactivate server

    Note right of browser: Browser re-renders notes including the new one
