# 0.6 – Spa New Note Diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note over browser,server: User creates new note on: https://studies.cs.helsinki.fi/exampleapp/spa

    Note right of browser: User types note text and clicks Save

    Note right of browser: JavaScript intercepts submit (event.preventDefault)

    Note right of browser: Note is added to local state and UI is updated immediately

    browser->>server: POST /new_note_spa
    activate server
    Note right of server: Server saves the new note
    server-->>browser: 201 Created
    deactivate server

    Note right of browser: No redirect, no page reload, no further HTTP requests
